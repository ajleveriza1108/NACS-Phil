# Third-Party Media Manifest

This file records third-party visual assets intentionally bundled with NACS-Phil.

## Usage policy

The three photographs below are used only as **illustrative learning photography** on the Homepage program cards and the Programs learning-stage panels.

They **do not depict NACS-Phil students, staff, classrooms, campus facilities, or school events** and must not be captioned or described as if they do.

Official NACS-Phil campus and student photography must continue to use the existing approved Gallery / Media workflows and consent rules.

The optimized derivatives are stored locally under:

`public/assets/phase36-experience/images/`

No Pexels image is hotlinked at runtime.
