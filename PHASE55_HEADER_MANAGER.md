# NACS-Phil Phase 55 - Header and Navigation Manager

Phase 55 makes public-header wording editable without code changes.

Authorized roles:
- Super Administrator (implicit full access)
- Principal
- Frontend Editor
- Text / Content Editor

Other specialized editors and teachers do not receive header-management permission.

Editable values include:
- header short name;
- full school name shown in the header;
- primary navigation labels;
- Resources label;
- mobile Academics and News & Media group labels;
- enrollment CTA text;
- academic PDF watermark.

The same managed school-name/header source is also used by Phase 54 academic PDFs, preventing the website and exported school documents from drifting into different identities.
